# Extreme Metal Vocal Converter

AI-powered converter for classic second-wave black metal vocals.

**Target styles:** Darkthrone (Transilvanian Hunger), Immortal / Abbath, Dark Funeral, Nargaroth.

## Stack
- Next.js 14
- Supabase (Auth + Storage)
- Vercel (deploy)

## Setup
1. Create a Supabase project
2. Enable Google + Email auth providers
3. Copy `.env.local.example` to `.env.local` and fill in keys
4. `npm install`
5. `npm run dev`
